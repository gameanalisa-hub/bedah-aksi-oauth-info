Kebijakan Privasi

Terakhir diperbarui: 25 November 2026

Kebijakan ini menjelaskan bagaimana BEDAH AKSI YouTube Analytics (“Aplikasi”) mengakses dan menangani data Google/YouTube saat pemilik channel menghubungkan akunnya.

1. Data yang diakses

Dengan persetujuan pemilik akun, Aplikasi menggunakan izin OAuth baca-saja untuk YouTube Analytics dan YouTube. Aplikasi mengambil metrik analitik channel, antara lain jumlah penayangan, estimasi menit ditonton, rata-rata durasi penayangan, subscriber yang diperoleh dan hilang, serta tren harian penayangan dan waktu tonton untuk periode laporan yang diminta. Kueri analitik dibatasi pada channel milik akun yang sedang terhubung.

2. Tujuan penggunaan

Data digunakan hanya untuk memantau performa channel BEDAH AKSI, membuat ringkasan dan tren analitik, serta menjalankan pemeriksaan validasi internal. Data tidak digunakan untuk iklan atau dijual kepada pihak lain.

3. Penyimpanan dan pemrosesan

Permintaan data dijalankan melalui workflow otomatis GitHub Actions. Kredensial OAuth disimpan sebagai GitHub Actions Secrets dan tidak ditampilkan dalam laporan. Hasil pemeriksaan dapat dimasukkan ke dalam laporan workflow (artifact) untuk ditinjau oleh pengelola repository. Masa penyimpanan artifact mengikuti konfigurasi retensi GitHub Actions pada repository terkait.

4. Pembagian data

Aplikasi menggunakan layanan Google/YouTube API untuk mengambil data yang diizinkan dan GitHub Actions untuk menjalankan proses otomatis serta menyimpan laporan. Aplikasi tidak menjual atau menyewakan data pengguna. Pemrosesan oleh Google dan GitHub juga tunduk pada kebijakan privasi masing-masing penyedia layanan.

5. Keamanan

Akses dibatasi pada izin baca-saja yang diperlukan. Token dan rahasia OAuth disimpan sebagai secrets pada repository, bukan di halaman publik. Pengelola menerapkan pembatasan akses repository dan workflow sesuai pengaturan akun GitHub.

6. Penghapusan atau pencabutan akses

Pemilik akun dapat mencabut akses Aplikasi melalui pengaturan koneksi pihak ketiga di Akun Google: myaccount.google.com/connections. Setelah akses dicabut, Aplikasi tidak dapat memperoleh data baru melalui koneksi tersebut. Untuk meminta peninjauan atau penghapusan laporan yang tersimpan, hubungi pengelola melalui alamat di bawah.

7. Privasi anak-anak

Aplikasi ini merupakan alat analitik internal untuk pengelola channel dan tidak ditujukan kepada anak-anak.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui jika cara kerja Aplikasi berubah. Versi terbaru akan dipublikasikan pada halaman ini beserta tanggal pembaruannya.

9. Kontak

Untuk pertanyaan privasi atau permintaan terkait data, hubungi pengelola di bedahaksi@gmail.com.
